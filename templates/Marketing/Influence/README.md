landing page, onboarding, a referral program, a sales script, or a
fundraising appeal, or reviewing any of these for manipulation, find the
skills that apply to the task in the table below and read them.

Do not read every skill file by default. Read only the skills whose

claims, and how to recognize and refuse its counterfeit. The book's
examples predate digital marketing; the skills carry a short "Current

fake urgency) matters.

# Context for AI: Persuasion

## 1. Shortcuts Serve People When the Signal Is True

People rely on shortcuts (a gift, a commitment, what others do, someone
they like, an expert, something rare) because those cues are usually
right. Honest marketing makes the cue true; manipulation fakes it.

## 2. Never Counterfeit a Cue

Do not invent scarcity, deadlines, reviews, user counts, credentials,
endorsements, or gifts with strings attached. When the user asks for one,
refuse that part and offer the honest version.

## 3. One Principle, Applied Well

Pick the principle that fits the decision the customer faces, and apply
it where it is true, rather than stacking every principle on one page.

## 4. Report It

Say which principles a piece of copy or a flow uses and what evidence
backs each claim.
