# Meaningful Names — AI Entry Point

## Purpose

This file is the entry point for the Meaningful Names skill collection. Use it to identify which skill to consult before applying naming guidelines to code.

## Available Skills

### `namesThatRevealTheirPurpose.md`

**Use when:** Writing, reviewing, refactoring, or improving code where variable, function, class, parameter, or other identifier names need to be created or evaluated.

**Guidance:** Read this skill to understand how to choose names that reveal their meaningful purpose, communicate intent, and reduce the need for explanatory comments.

### `namingRules.md`

**Use when:** Choosing or renaming identifiers, classes, modules, or files; settling naming conventions (prefixes, Hungarian notation, `I`-prefixed interfaces); or reviewing names that are misleading, noisy, unpronounceable, unsearchable, cute, or inconsistent.

**Guidance:** Read this skill for the remaining naming rules — avoiding disinformation and encodings, making meaningful distinctions, one word per concept, domain names and context — plus a naming workflow and how to present name suggestions.

## Instructions for the AI

1. Start here when naming-related guidance is needed.
2. Read `namesThatRevealTheirPurpose.md` when a name fails to communicate why something exists, what it does, or how it is used.
3. Read `namingRules.md` for any other naming decision or review.
4. Apply the skill's guidance to the specific code and context being worked on.
5. Do not read unrelated skills or search through the entire skill collection unnecessarily.
6. If additional skills are added in the future, register them here with a clear description of when each should be used.
